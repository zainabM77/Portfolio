Projects at BMO

Dynamic scaling for a shared CDK module

I extended BMO's internal AWS CDK module so development teams can add dynamic Auto Scaling to their infrastructure through one standard, reusable configuration instead of setting up each Auto Scaling group by hand.

I researched target tracking, step, simple and predictive scaling and compared how they behave behind Application and Network Load Balancers. I then implemented support in TypeScript for metrics such as average CPU utilization, network throughput and ALB requests per target, validated scaling behaviour under load in lower environments with CloudWatch metrics and alarms, and wrote developer documentation to help teams choose the right policy.

Built with AWS CDK, TypeScript, EC2 Auto Scaling, CloudWatch, Application and Network Load Balancers

Change request portal

Team project

An internal web portal my team is building to help cloud engineers create change requests for change management. Its backend connects to a central API that reads, creates and validates change requests in ServiceNow. Scheduled functions assign tasks and send email follow-ups, and a history and analytics service keeps a record of activity.

Built with AWS Lambda, Amazon ECS, API Gateway, ServiceNow API

Automated scaling notifications

An event-driven monitoring system, built as part of a larger team project, that watches EC2 Auto Scaling activity. When the group scales out or in, an EventBridge rule captures the event and publishes it to an SNS topic, which emails the team every time an instance is created or terminated.

I designed the architecture with my team and defined it in two AWS CDK stacks: the EventBridge rule, event bus, IAM role, SQS queue and SNS topic. I then deployed and validated it in a lower environment before it moved to higher ones.

Built with AWS CDK, TypeScript, EventBridge, SNS, SQS, IAM, EC2 Auto Scaling

Load-balanced auto scaling

A setup demonstrating load balancing with an Auto Scaling group, which adds or removes server instances as traffic changes. An Application Load Balancer spreads incoming requests across the healthy instances in its target group to keep load even and the service available.

I built and tested it in a lower environment, monitoring health checks, scaling and traffic distribution, then replicated it in a higher, production-like environment. I worked through connectivity issues directly with AWS and documented the architecture, steps and results in a developer guide.

Built with EC2 Auto Scaling, Application Load Balancer, target groups, health checks
